# Hola, soy Daymer 👋
**Ingeniero de software · IA y automatización** · Medellín, Colombia

Diseño y construyo sistemas donde los agentes de IA hacen trabajo real:
herramientas para desarrolladores, automatizaciones y productos full-stack
que van de una idea a producción. Fundador en [Sol3](https://sol3.lat).

## En qué trabajo
- 🤖 **Agentes y flujos de trabajo con LLMs:** orquestación, reglas y herramientas para Claude Code, Codex y opencode.
- ⚙️ **Automatización:** scraping a Markdown, pipelines de datos e integraciones.
- 🧱 **Producto full-stack:** Vue 3, TypeScript, Supabase y Flutter.
- 🦀 **Herramientas de terminal:** Rust.
